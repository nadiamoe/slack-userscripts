# slack-userscripts

My personal userscripts for Slack's web client. Install them with a userscript manager like Tampermonkey or Violentmonkey.

| Script | What it does |
| --- | --- |
| `slack-keep-threads-unread.user.js` | Stops the Threads view from marking threads as read when you navigate. `Ctrl+Alt+R` toggles it. |
| `slack-mark-thread-read.user.js` | Adds a "Mark as Read" button to each thread in the Threads view. Works together with the script above. |
| `slack-mark-read.user.js` | Pressing `r` marks the top unread group as read in the All unreads view. |
